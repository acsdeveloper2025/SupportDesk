# Roles API

Roles are tenant-scoped labels containing permission grants. Code authorizes permissions, not role names.

| Method / URI                          | Authentication        | Authorization | Request                                 | Response                    | Validation                                       | Errors                                  | Page/filter/sort                               | Rate limit         | Example                       |
| ------------------------------------- | --------------------- | ------------- | --------------------------------------- | --------------------------- | ------------------------------------------------ | --------------------------------------- | ---------------------------------------------- | ------------------ | ----------------------------- |
| `GET /api/v1/roles`                   | Active tenant session | `role.read`   | None                                    | Roles and grant counts      | Tenant context                                   | `AUTH_FORBIDDEN`                        | Cursor; filter system/custom/status; sort name | Normal read        | Role admin list.              |
| `POST /api/v1/roles`                  | Active tenant session | `role.create` | Name, description, grants               | Created role                | Unique name; actor can grant permissions         | `VALIDATION_FAILED`, `AUTH_FORBIDDEN`   | None                                           | Sensitive mutation | Create Department Admin role. |
| `GET /api/v1/roles/{role_id}`         | Active tenant session | `role.read`   | None                                    | Role detail and permissions | Same tenant                                      | `NOT_FOUND`                             | None                                           | Normal read        | View role.                    |
| `PATCH /api/v1/roles/{role_id}`       | Active tenant session | `role.update` | Name/description/status/grants, version | Updated role                | System role restrictions; actor can grant/revoke | `PRECONDITION_FAILED`, `AUTH_FORBIDDEN` | None                                           | Sensitive mutation | Update grants.                |
| `DELETE /api/v1/roles/{role_id}`      | Active tenant session | `role.delete` | Version, replacement role optional      | Soft-deleted role           | Cannot delete system/last-admin dependency       | `CONFLICT`                              | None                                           | Sensitive mutation | Retire unused role.           |
| `GET /api/v1/roles/{role_id}/members` | Active tenant session | `user.read`   | None                                    | Membership list             | Same tenant                                      | `AUTH_FORBIDDEN`                        | Cursor; filter status; sort name               | Normal read        | Review role members.          |

Role changes invalidate authorization caches within the window defined in [../08-rbac.md](../08-rbac.md).
