# Notifications API

Related: [../notification-events.md](../notification-events.md), [../email-templates.md](../email-templates.md), [../11-notifications.md](../11-notifications.md).

| Method / URI                                                | Authentication         | Authorization                                       | Request                                       | Response                     | Validation                                              | Errors                                      | Page/filter/sort                             | Rate limit         | Example                        |
| ----------------------------------------------------------- | ---------------------- | --------------------------------------------------- | --------------------------------------------- | ---------------------------- | ------------------------------------------------------- | ------------------------------------------- | -------------------------------------------- | ------------------ | ------------------------------ |
| `GET /api/v1/notifications`                                 | Active tenant session  | Own notifications                                   | None                                          | In-app notification list     | Active membership                                       | `AUTH_REQUIRED`                             | Cursor; filter unread/event; sort created_at | Normal read        | Notification drawer.           |
| `PATCH /api/v1/notifications/{notification_id}`             | Active tenant session  | Own notification                                    | Read/archive state, version                   | Updated notification         | Own recipient                                           | `NOT_FOUND`, `PRECONDITION_FAILED`          | None                                         | Normal mutation    | Mark read.                     |
| `GET /api/v1/notification-preferences`                      | Active tenant session  | Own preferences or `notification.preference.read`   | None                                          | Preferences by event/channel | Active membership                                       | `AUTH_FORBIDDEN`                            | None                                         | Normal read        | Preference screen.             |
| `PATCH /api/v1/notification-preferences`                    | Active tenant session  | Own preferences or `notification.preference.update` | Preferences and version                       | Updated preferences          | Mandatory notices cannot be disabled                    | `VALIDATION_FAILED`                         | None                                         | Mutation           | Disable marketing-like alerts. |
| `GET /api/v1/notification-templates`                        | Active tenant session  | `notification.template.read`                        | None                                          | Template list                | Tenant context                                          | `AUTH_FORBIDDEN`                            | Cursor; filter event/locale/status; sort key | Normal read        | Admin template list.           |
| `POST /api/v1/notification-templates`                       | Active tenant session  | `notification.template.create`                      | Key, channel, locale, subject/body, variables | Draft template               | Escaping/variable validation                            | `VALIDATION_FAILED`                         | None                                         | Sensitive mutation | Create SLA warning template.   |
| `PATCH /api/v1/notification-templates/{template_id}`        | Active tenant session  | `notification.template.update`                      | Draft fields, version                         | Updated draft                | Valid variables/locales                                 | `PRECONDITION_FAILED`                       | None                                         | Sensitive mutation | Edit draft.                    |
| `POST /api/v1/notification-templates/{template_id}/publish` | Active tenant session  | `notification.template.publish`                     | Version, reason                               | Published immutable version  | Preview passes; required variables supplied             | `BUSINESS_RULE_FAILED`                      | None                                         | Sensitive mutation | Publish template.              |
| `POST /api/v1/admin/notifications/provider-webhooks`        | Provider/internal auth | Platform internal                                   | Provider event and signature                  | Accepted webhook             | Signature, replay, tenant mapping by provider reference | `AUTH_INVALID_SIGNATURE`, `REPLAY_DETECTED` | None                                         | Provider throttle  | Bounce webhook.                |

Notification delivery state is eventually consistent and visible through audit/operations views where authorized.
