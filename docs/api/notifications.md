## In-app creation service

`NotificationsService.create` / `createSafe` is the synchronous entry point other modules call after a committed domain mutation (assignment, status change, public/internal comment, attachment upload, SLA warning/breach). Behavior:

- Tenant-scoped persistence in `notifications`
- Suppresses self-notifications (actor == recipient)
- Honors `notification_preferences` for channel `in_app` (default enabled when unset)
- Mandatory security events (`auth.session.revoked`, `settings.security.updated`) cannot be suppressed by preference
- `createSafe` never fails the parent business operation

Email/SMS/push/webhook delivery remains deferred and will later consume the same event types without changing callers.
