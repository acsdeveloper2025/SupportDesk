## Engine behavior

- Ticket create selects the first matching published policy and starts response + resolution Targets against the published Business Schedule version.
- Public agent Comment (author ≠ requester) completes the response Target.
- Transition to `solved` completes the resolution Target.
- `pending` / `on_hold` pause according to captured policy flags; resume extends `dueAt` by remaining business time.
- Breach and warning evaluation runs on Ticket mutations and on SLA status/timer reads (no background worker in this slice).
- In-app notifications: `sla.warning`, `sla.breached` to assignee (or requester if unassigned). Email deferred.
