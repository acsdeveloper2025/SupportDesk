# Tickets API

Related: [../09-ticket-lifecycle.md](../09-ticket-lifecycle.md), [../workflow-matrix.md](../workflow-matrix.md), [comments.md](comments.md), [attachments.md](attachments.md).

| Method / URI                                   | Authentication                                      | Authorization                                         | Request                                                                                          | Response                                              | Validation                                                     | Errors                                                       | Page/filter/sort                                                                                    | Rate limit           | Example                 |
| ---------------------------------------------- | --------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- | -------------------- | ----------------------- |
| `GET /api/v1/tickets`                          | Active tenant session                               | `ticket.read` scoped to own/organization/group/tenant | None                                                                                             | Ticket list                                           | Tenant scope and filters allowed                               | `AUTH_FORBIDDEN`                                             | Cursor; filter status/priority/assignee/group/tag/SLA/search; sort updated/created/priority/sla_due | Queue read           | Agent queue.            |
| `POST /api/v1/tickets`                         | Active tenant session or verified requester channel | `ticket.create`                                       | Subject, description, channel, requester, organization, priority, custom fields, idempotency key | Created ticket with initial comment                   | Required subject/body; valid requester; same tenant references | `VALIDATION_FAILED`, `CONFLICT`, `RATE_LIMITED`              | None                                                                                                | Mutation/idempotency | Submit support request. |
| `GET /api/v1/tickets/{ticket_id}`              | Active tenant session                               | `ticket.read` scoped to resource                      | None                                                                                             | Ticket detail, version, SLA, visible comments summary | Same tenant; source auth recheck                               | `NOT_FOUND` enumeration-safe                                 | None                                                                                                | Normal read          | Open ticket.            |
| `PATCH /api/v1/tickets/{ticket_id}`            | Active tenant session                               | Field-specific permissions                            | Version, fields to change                                                                        | Updated ticket                                        | Optimistic version; valid transitions/fields                   | `VALIDATION_FAILED`, `PRECONDITION_FAILED`, `AUTH_FORBIDDEN` | None                                                                                                | Mutation             | Change priority.        |
| `POST /api/v1/tickets/{ticket_id}/assignments` | Active tenant session                               | `ticket.assign`                                       | Agent ID or group ID, reason, version                                                            | Updated assignment                                    | Assignee active in tenant and visible                          | `VALIDATION_FAILED`, `PRECONDITION_FAILED`                   | None                                                                                                | Mutation             | Assign to group.        |
| `POST /api/v1/tickets/{ticket_id}/transitions` | Active tenant session                               | Status-specific transition permission                 | Target status, reason/resolution, version                                                        | Updated status                                        | Allowed transition in workflow matrix; approval if required    | `BUSINESS_RULE_FAILED`, `PRECONDITION_FAILED`                | None                                                                                                | Mutation             | Solve ticket.           |
| `POST /api/v1/tickets/{ticket_id}/links`       | Active tenant session                               | `ticket.link`                                         | Linked ticket ID, relationship                                                                   | Link created                                          | Same tenant; no self-link; relationship allowed                | `VALIDATION_FAILED`, `CONFLICT`                              | None                                                                                                | Mutation             | Link follow-up ticket.  |
| `GET /api/v1/tickets/{ticket_id}/activity`     | Active tenant session                               | `ticket.read` plus audit visibility                   | None                                                                                             | Timeline of safe events                               | Same tenant                                                    | `AUTH_FORBIDDEN`                                             | Cursor; filter type; sort time                                                                      | Normal read          | Ticket timeline.        |
| `GET /api/v1/tickets/search`                   | Active tenant session                               | `ticket.read`                                         | Query and filters                                                                                | Search results with freshness metadata                | Query length and filters allowed                               | `VALIDATION_FAILED`, `RATE_LIMITED`                          | Cursor; filter status/tag/assignee; sort relevance/updated                                          | Search throttle      | Search tickets.         |

Ticket mutations emit audit events, domain events, and outbox records atomically.
