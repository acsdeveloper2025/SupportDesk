# Comments API

Related: [tickets.md](tickets.md), [attachments.md](attachments.md), [../11-notifications.md](../11-notifications.md).

| Method / URI                                | Authentication        | Authorization                                        | Request                                           | Response                      | Validation                                                                              | Errors                                        | Page/filter/sort                                  | Rate limit           | Example                       |
| ------------------------------------------- | --------------------- | ---------------------------------------------------- | ------------------------------------------------- | ----------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------- | ------------------------------------------------- | -------------------- | ----------------------------- |
| `GET /api/v1/tickets/{ticket_id}/comments`  | Active tenant session | `comment.read` scoped to visibility                  | None                                              | Visible comments              | Ticket same tenant; internal visibility enforced                                        | `AUTH_FORBIDDEN`, `NOT_FOUND`                 | Cursor; filter visibility/source; sort created_at | Normal read          | Load timeline.                |
| `POST /api/v1/tickets/{ticket_id}/comments` | Active tenant session | `comment.public.create` or `comment.internal.create` | Body, visibility, attachment IDs, idempotency key | Created comment               | Body required; visibility allowed; attachments clean/same ticket unless quarantine flow | `VALIDATION_FAILED`, `AUTH_FORBIDDEN`         | None                                              | Mutation/idempotency | Reply to requester.           |
| `GET /api/v1/comments/{comment_id}`         | Active tenant session | `comment.read` scoped to visibility                  | None                                              | Comment detail                | Same tenant and ticket visibility                                                       | `NOT_FOUND`                                   | None                                              | Normal read          | View comment.                 |
| `PATCH /api/v1/comments/{comment_id}`       | Active tenant session | `comment.update` limited policy                      | Body/version for editable draft only              | Updated comment               | Only permitted edit window/draft; visibility immutable                                  | `BUSINESS_RULE_FAILED`, `PRECONDITION_FAILED` | None                                              | Sensitive mutation   | Correct typo before dispatch. |
| `DELETE /api/v1/comments/{comment_id}`      | Active tenant session | `comment.delete`                                     | Version, reason                                   | Redacted/soft-deleted comment | Retention and audit policy; public dispatch constraints                                 | `CONFLICT`, `AUTH_FORBIDDEN`                  | None                                              | Sensitive mutation   | Redact sensitive data.        |

Internal comments must never be returned to Requesters or embedded in requester notifications.
