# Organizations API

Organizations group Requesters inside a tenant. Related: [../database/TABLES.md](../database/TABLES.md), [../permissions-matrix.md](../permissions-matrix.md).

| Method / URI                                          | Authentication        | Authorization                        | Request                                    | Response                  | Validation                                           | Errors                                     | Page/filter/sort                                           | Rate limit           | Example                        |
| ----------------------------------------------------- | --------------------- | ------------------------------------ | ------------------------------------------ | ------------------------- | ---------------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------- | -------------------- | ------------------------------ |
| `GET /api/v1/organizations`                           | Active tenant session | `organization.read`                  | None                                       | Organization list         | Tenant context required                              | `AUTH_REQUIRED`, `AUTH_FORBIDDEN`          | Cursor; filter `status`, `name`; sort `name`, `created_at` | Normal read          | List active organizations.     |
| `POST /api/v1/organizations`                          | Active tenant session | `organization.create`                | Name, external reference, metadata         | Created organization      | Unique tenant name/reference; required name          | `VALIDATION_FAILED`, `CONFLICT`            | None                                                       | Mutation/idempotency | Create requester organization. |
| `GET /api/v1/organizations/{organization_id}`         | Active tenant session | `organization.read`                  | None                                       | Organization detail       | Same tenant                                          | `NOT_FOUND` enumeration-safe               | None                                                       | Normal read          | View organization.             |
| `PATCH /api/v1/organizations/{organization_id}`       | Active tenant session | `organization.update`                | Allowed profile/status fields with version | Updated organization      | Version match; unique fields                         | `VALIDATION_FAILED`, `PRECONDITION_FAILED` | None                                                       | Mutation             | Rename organization.           |
| `DELETE /api/v1/organizations/{organization_id}`      | Active tenant session | `organization.delete`                | Version, reason                            | Soft-deleted organization | No active blocking policy or migration path selected | `CONFLICT`, `PRECONDITION_FAILED`          | None                                                       | Sensitive mutation   | Retire organization.           |
| `GET /api/v1/organizations/{organization_id}/tickets` | Active tenant session | `ticket.read` scoped to organization | None                                       | Ticket list               | Same tenant and scope                                | `AUTH_FORBIDDEN`                           | Cursor; filter status/priority; sort updated/SLA           | Queue read           | Organization ticket history.   |

All organization mutations emit audit events and invalidate organization-scoped permission/search projections.
