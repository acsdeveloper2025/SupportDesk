# Users and memberships API

Related: [authentication.md](authentication.md), [../08-rbac.md](../08-rbac.md), [../permissions-matrix.md](../permissions-matrix.md).

| Method / URI                                     | Authentication        | Authorization                        | Request                           | Response                         | Validation                                                      | Errors                                | Page/filter/sort                                           | Rate limit         | Example              |
| ------------------------------------------------ | --------------------- | ------------------------------------ | --------------------------------- | -------------------------------- | --------------------------------------------------------------- | ------------------------------------- | ---------------------------------------------------------- | ------------------ | -------------------- |
| `GET /api/v1/users`                              | Active tenant session | `user.read`                          | None                              | Tenant-visible users/memberships | Tenant context                                                  | `AUTH_FORBIDDEN`                      | Cursor; filter role/group/status/search; sort name/created | Normal read        | User admin list.     |
| `POST /api/v1/users/invitations`                 | Active tenant session | `user.invite`                        | Email, role IDs, groups, message  | Invitation record                | Email format; roles/groups same tenant; inviter can grant roles | `VALIDATION_FAILED`, `AUTH_FORBIDDEN` | None                                                       | Invite throttles   | Invite agent.        |
| `GET /api/v1/users/{user_id}`                    | Active tenant session | `user.read` or own profile           | None                              | User and membership detail       | Same tenant visibility                                          | `NOT_FOUND`                           | None                                                       | Normal read        | View profile.        |
| `PATCH /api/v1/users/{user_id}/membership`       | Active tenant session | `user.membership.update`             | Status, groups, metadata, version | Updated membership               | Cannot remove last active tenant admin; version match           | `CONFLICT`, `PRECONDITION_FAILED`     | None                                                       | Sensitive mutation | Suspend membership.  |
| `POST /api/v1/users/{user_id}/roles`             | Active tenant session | `role.assign`                        | Role IDs, version                 | Updated assignments              | Actor holds grantable permissions; same tenant                  | `AUTH_FORBIDDEN`, `VALIDATION_FAILED` | None                                                       | Sensitive mutation | Assign manager role. |
| `DELETE /api/v1/users/{user_id}/roles/{role_id}` | Active tenant session | `role.revoke`                        | Version, reason                   | Updated assignments              | Cannot remove last admin; actor cannot revoke beyond authority  | `CONFLICT`, `AUTH_FORBIDDEN`          | None                                                       | Sensitive mutation | Revoke role.         |
| `GET /api/v1/users/{user_id}/activity`           | Active tenant session | `audit.read` or own limited activity | None                              | Audit/activity list              | Same tenant                                                     | `AUTH_FORBIDDEN`                      | Cursor; filter action/date; sort time                      | Audit read         | View user activity.  |

All membership, role, invitation, suspension, and revocation actions are audited.
