# Permissions API

Permissions are stable global keys documented in [../permissions-matrix.md](../permissions-matrix.md). Tenants can assign permissions through roles but cannot create arbitrary permission keys.

| Method / URI                        | Authentication        | Authorization                              | Request                      | Response                                  | Validation                                            | Errors                                | Page/filter/sort                       | Rate limit                 | Example                       |
| ----------------------------------- | --------------------- | ------------------------------------------ | ---------------------------- | ----------------------------------------- | ----------------------------------------------------- | ------------------------------------- | -------------------------------------- | -------------------------- | ----------------------------- |
| `GET /api/v1/permissions`           | Active tenant session | `permission.read`                          | None                         | Permission catalogue                      | Tenant context                                        | `AUTH_FORBIDDEN`                      | Filter resource/action/scope; sort key | Normal read                | Build role editor.            |
| `GET /api/v1/permissions/matrix`    | Active tenant session | `permission.read`                          | Role IDs optional            | Matrix of roles to permissions            | Same tenant roles                                     | `VALIDATION_FAILED`                   | None                                   | Normal read                | Permission matrix UI.         |
| `GET /api/v1/permissions/effective` | Active tenant session | Own session                                | None                         | Effective permissions for selected tenant | Active membership                                     | `AUTH_REQUIRED`                       | None                                   | Normal read                | Bootstrap UI abilities.       |
| `POST /api/v1/permissions/check`    | Active tenant session | Own session or admin diagnostic permission | Resource/action/scope/target | Allow/deny diagnostic with safe reason    | Target tenant visibility; no sensitive existence leak | `AUTH_FORBIDDEN`, `VALIDATION_FAILED` | None                                   | Strict diagnostic throttle | Explain denied action safely. |

Permission diagnostics must never reveal foreign tenant resource existence.
