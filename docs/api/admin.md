# Admin and platform operations API

These endpoints are for tenant administration and platform operations. Platform operator access follows [../07-security-compliance.md](../07-security-compliance.md) and [../audit-events.md](../audit-events.md).

| Method / URI                                                    | Authentication                               | Authorization                              | Request                          | Response                   | Validation                               | Errors                                   | Page/filter/sort                                      | Rate limit                 | Example                          |
| --------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------ | -------------------------------- | -------------------------- | ---------------------------------------- | ---------------------------------------- | ----------------------------------------------------- | -------------------------- | -------------------------------- |
| `GET /api/v1/admin/health`                                      | Authenticated operator or protected probe    | `platform.health.read` or probe credential | None                             | Health/readiness summary   | Probe scope                              | `AUTH_FORBIDDEN`                         | None                                                  | Probe scoped               | Readiness check.                 |
| `GET /api/v1/admin/operations`                                  | Active tenant admin/operator session         | `operation.read`                           | None                             | Async operations           | Tenant/operator scope                    | `AUTH_FORBIDDEN`                         | Cursor; filter state/type; sort created_at            | Normal read                | View export/backfill operations. |
| `GET /api/v1/admin/outbox/stats`                                | Tenant admin/operator                        | `admin.outbox.manage`                      | None                             | Outbox backlog summary     | Scope enforced; no foreign content       | `AUTH_FORBIDDEN`                         | None                                                  | Ops throttle               | Inspect delayed jobs.            |
| `GET /api/v1/admin/outbox/events`                               | Tenant admin/operator                        | `admin.outbox.manage`                      | Filters                          | Outbox event list          | Scope enforced; no foreign content       | `AUTH_FORBIDDEN`                         | Offset; filter state/type; sort age                   | Ops throttle               | Inspect failed events.           |
| `POST /api/v1/admin/outbox/events/{event_id}/replay`            | Tenant admin/operator                        | `admin.outbox.replay`                      | None                             | Replay operation           | Event replay-safe; same tenant           | `BUSINESS_RULE_FAILED`, `AUTH_FORBIDDEN` | None                                                  | Strict privileged mutation | Replay failed notification.      |
| `POST /api/v1/admin/outbox/events/retry-failed`                 | Tenant admin/operator                        | `admin.outbox.replay`                      | None                             | Retry summary              | Same-tenant failed/dead-letter events    | `BUSINESS_RULE_FAILED`, `AUTH_FORBIDDEN` | None                                                  | Strict privileged mutation | Retry failed batch.              |
| `POST /api/v1/admin/operator-elevations`                        | Platform operator with MFA                   | `platform.elevation.request`               | Tenant, scope, purpose, duration | Pending/approved elevation | Requires approver, bounded scope, reason | `AUTH_FORBIDDEN`, `VALIDATION_FAILED`    | None                                                  | Highly restricted          | Request support access.          |
| `POST /api/v1/admin/operator-elevations/{elevation_id}/approve` | Authorized approver                          | `platform.elevation.approve`               | Approval decision, reason        | Elevation state            | Cannot self-approve; expiry required     | `AUTH_FORBIDDEN`, `BUSINESS_RULE_FAILED` | None                                                  | Highly restricted          | Approve elevation.               |
| `DELETE /api/v1/admin/operator-elevations/{elevation_id}`       | Operator/approver/security                   | `platform.elevation.revoke`                | Reason                           | Revoked elevation          | Active elevation exists                  | `NOT_FOUND`                              | None                                                  | Highly restricted          | Revoke support access.           |
| `GET /api/v1/admin/audit-events`                                | Tenant admin/auditor/operator with elevation | `audit.read`                               | Filters                          | Audit events               | Scope and content policy enforced        | `AUTH_FORBIDDEN`                         | Cursor; filter actor/action/target/date; sort instant | Audit throttle             | Platform investigation.          |

Operator APIs must never bypass tenant isolation. Elevated paths are separate, time-bound, and fully audited.
