# Settings API

Tenant settings are versioned configuration records. Related: [../database/TABLES.md](../database/TABLES.md), [../06-tenant-isolation.md](../06-tenant-isolation.md).

| Method / URI                      | Authentication        | Authorization                             | Request                                             | Response                       | Validation                                     | Errors                                     | Page/filter/sort                             | Rate limit          | Example                  |
| --------------------------------- | --------------------- | ----------------------------------------- | --------------------------------------------------- | ------------------------------ | ---------------------------------------------- | ------------------------------------------ | -------------------------------------------- | ------------------- | ------------------------ |
| `GET /api/v1/settings`            | Active tenant session | `settings.read`                           | None                                                | Tenant settings namespaces     | Tenant context                                 | `AUTH_FORBIDDEN`                           | None                                         | Normal read         | Admin settings page.     |
| `PATCH /api/v1/settings/profile`  | Active tenant session | `settings.update`                         | Branding, locale, timezone, contact fields, version | Updated settings draft/current | Valid locale/timezone; safe branding assets    | `VALIDATION_FAILED`, `PRECONDITION_FAILED` | None                                         | Sensitive mutation  | Update tenant branding.  |
| `PATCH /api/v1/settings/security` | Active tenant session | `settings.security.update`                | MFA/session/support-access policies, version        | Updated security settings      | Cannot weaken below platform baseline          | `BUSINESS_RULE_FAILED`, `AUTH_FORBIDDEN`   | None                                         | Privileged mutation | Require MFA.             |
| `PATCH /api/v1/settings/email`    | Active tenant session | `settings.email.update`                   | Sender domains, reply routing, footer, version      | Updated email config           | Domain verification required before activation | `VALIDATION_FAILED`, `DOMAIN_UNVERIFIED`   | None                                         | Privileged mutation | Configure support email. |
| `PATCH /api/v1/settings/quotas`   | Active tenant session | `settings.quota.update` or platform admin | Attachment/report/API limits                        | Updated quotas                 | Within entitlement/platform limits             | `AUTH_FORBIDDEN`, `QUOTA_INVALID`          | None                                         | Privileged mutation | Adjust storage quota.    |
| `GET /api/v1/settings/audit`      | Active tenant session | `settings.audit.read`                     | None                                                | Settings change history        | Tenant context                                 | `AUTH_FORBIDDEN`                           | Cursor; filter namespace/actor; sort instant | Audit read          | Review config changes.   |

Settings changes are audited and may require publication/approval if they affect security, email identity, workflow, SLA, or retention behavior.
